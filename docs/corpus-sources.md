## Notes

- **RA 10173** is served from privacy.gov.ph behind Cloudflare, which returns 403
  to scripted requests on that path. A fallback to the Senate copy is in the
  manifest; if both refuse, open either link in a browser and save the PDF to
  `corpus/ra-10173.pdf` by hand. The text is identical.
- The NPC publishes **FAQ companions** to several circulars (2023-05, 2023-06,
  2023-07, the Competency Program, Administrative Fines). They are useful and
  official but are written as Q&A rather than numbered sections, so citing them
  precisely is awkward. Left out of v1 on purpose.
- Amendments to RA 10173 have been pending in Congress across several sessions.
  Re-check the corpus before you demo, and record the date you last verified it
  in the README.
